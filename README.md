# Survivor

A daily NYT Mini Crossword player, built for the Home Screen.

Open the link, tap the date picker to play an older puzzle, and it saves your progress locally.

## Add to Home Screen (iOS)

1. Open the site in **Safari**
2. Tap **Share** → **Add to Home Screen**

## Notes

- Progress and settings are stored in your browser's local storage (per device).
- Dark mode follows your device theme, or set it manually in Settings.
- Puzzle data is bundled under `puzzles/`.
